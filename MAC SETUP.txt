GM CAMPAIGN COCKPIT - MAC FIRST RUN

1. Install a current Node.js LTS release from:
   https://nodejs.org/en/download

2. Keep the application beside your campaign folders, or copy
   ".env.example" to ".env" and set VAULT_ROOT.

3. Double-click "Start GM Cockpit Mac.command".

4. If macOS says the launcher cannot be executed, open Terminal and run:

   chmod +x "/path/to/GM Campaign Cockpit/Start GM Cockpit Mac.command"

   You can type "chmod +x " and drag the launcher into Terminal.

5. Keep the launcher Terminal window open while using the cockpit.
   Press Control-C when the session is finished.

The local DM interface opens at:
http://127.0.0.1:4173

For trusted-LAN play, configure HOST, ALLOW_REMOTE_DM, and TABLE_PIN in .env.
Do not expose the server directly to the public internet.

Notes save to the selected campaign's "Session Notes Workbook.md". Existing
workbooks are backed up before a save; if the backup fails, the workbook is not
changed.
